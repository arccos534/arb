## Назначение и устройство

Arbitrage Lab MVP v0.2.0 — локальное исследовательское приложение: публичные котировки Polymarket и Limitless, поиск пар, виртуальное исполнение двух сторон, комиссии, риск, P&L и диагностика. Реальные ордера и переводы не реализованы. Bybit моделируется; Drift/Hedgehog используются как дополнительные источники каталога без исполнения.

Стек: Node.js 24, TypeScript с `strict`, ES modules, Decimal.js, Zod, REST/WebSocket и Socket.IO. Интерфейс — HTML/CSS/JavaScript без отдельного фронтенд-фреймворка. Для локального MVP PostgreSQL не требуется; Docker Compose и опциональное PostgreSQL-хранилище исследовательских данных присутствуют.

## Локальный запуск

```powershell
Set-Location -LiteralPath 'E:\informatica\кнопка деньги'
npm.cmd start
```

После запуска интерфейс доступен по `http://127.0.0.1:4317`. В новой сессии виртуальная торговля изначально на паузе. `.env` для запуска с локальными настройками по умолчанию не требуется.

Для штатного фонового запуска вместо `npm.cmd start`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\status-local.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\stop-local.ps1
```

Команда `reset:local` предназначена для отдельного сброса с архивированием; при подготовке этой копии она не выполнялась.
