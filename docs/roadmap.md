# Состояние плана после MVP v0.2

| Этап | Состояние | Результат / следующий критерий |
| --- | --- | --- |
| Доступность реальной торговли | Не подтверждена | Пользователь в РФ, VPS в NL; зарубежный сервер не заменяет разрешённый доступ |
| Стек и настройки | Готово | TypeScript, Node.js 24, точные числа, параметры в UI |
| Публичные REST/WS и поиск кандидатов | Готово | Нормализация, горизонт, cursor/page pagination, явное неполное покрытие |
| Проверка конкретных контрактов | Механизм готов | UI с пятью критериями, обоснованием, хешами и сроком действия; рыночные пары не одобрены автоматически |
| Симуляция исполнения | Готово для MVP | Виртуальные балансы, резервы, будущий снимок, FAK, отказы/частичные fills, аварийный выход |
| Учёт и P&L | Готово для MVP | Денежный ledger, реализованный/нереализованный P&L, ликвидационная оценка, график |
| Получение выплат | Виртуально готово | Публичные окончательные результаты каждой площадки; неподдержанный статус остаётся в ожидании |
| Bybit-балансировка | Виртуально готово | Депозит/вывод/транзит/комиссия внутри модели; реального подключения нет |
| UI и поля подключений | Готово | Обзор, пары, сделки, журнал, параметры; API/RPC поля — несохраняемые заглушки |
| Диагностика и экспорт | Готово | Raw REST/WS, события, стаканы, параметры, транзакции, JSON/CSV/gzip, лимит диска |
| Локальные автоматические и браузерные проверки | Выполнены | Типизация, модульные/HTTP тесты, браузерный сценарий; детали в validation.md |
| Пользовательский локальный бета-тест | Следующий шаг | Нормальный и аварийные сценарии, перезапуск, настройки, экспорт, понимание P&L |
| VPS | Подготовлено, не размещено | После локальной проверки — отдельный запуск, нагрузка, private loopback UI через SSH |
| Наблюдение 2–4 недели | Не выполнено | Независимые события, задержки, стоимость оборота и достоверность модели |
| Реальные ордера/кошельки/выводы | Не реализованы | Разрешённый доступ, подтверждённая экономика, отдельная реализация с малыми реальными тестами |

Модель не подменяет рыночные сделки демонстрационными результатами. Каждый источник имеет отдельную сессию и баланс. Положительный снимок не считается закрытой прибылью. Процесс не начинает новые входы сам после перезапуска, но сохраняет открытые виртуальные позиции и продолжает проверять расчёт.
